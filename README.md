# Карта концертов группы АЗОН

Веб-приложение, которое парсит сайт https://www.az0n.ru/main/live/ и отображает на карте города, в которых запланированы концерты группы АЗОН.

## Функционал

- Парсинг сайта az0n.ru для получения списка концертов
- Извлечение даты и города каждого концерта
- Геокодирование городов (получение координат)
- Отображение интерактивной карты с метками городов
- Боковая панель со списком всех концертов
- При клике на элемент списка карта перемещается к соответствующему городу

## Установка и запуск

### Требования

- Python 3.8+
- pip

### Установка зависимостей

```bash
pip install flask requests beautifulsoup4 geopy
```

### Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Структура проекта

- `app.py` - основной файл приложения (Flask backend + HTML template)
- `README.md` - документация

## API

### GET /api/concerts

Возвращает JSON массив с информацией о концертах:

```json
[
  {
    "date": "12.09.2026",
    "city": "Дубна",
    "lat": 56.7362705,
    "lng": 37.1623696
  },
  ...
]
```

### GET /

Возвращает HTML страницу с интерактивной картой.

## Технологии

- **Backend**: Flask (Python)
- **Парсинг**: BeautifulSoup4, requests
- **Геокодирование**: geopy (Nominatim API)
- **Frontend**: Leaflet.js (карты), CartoDB (тайлы)

## Примечания

- Приложение использует бесплатный Nominatim API для геокодирования городов
- Результаты геокодирования кэшируются в памяти для уменьшения количества запросов
- Карта использует темную тему для лучшей видимости меток
